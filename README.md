# Roamify Travels - Travel Agency Landing Page

A modern and professional travel agency website built with Next.js and Tailwind CSS.

## Live Demo
**[View Live Site](https://iqraaslam2207-collab.github.io/roamify-travels/)**

## Features
- Beautiful hero section with stunning images
- Interactive booking inquiry popup
- Popular destinations showcase
- Responsive design for all devices
- Clean and modern UI

## Tech Stack
- Next.js
- Tailwind CSS
- React

## How to Run Locally
```bash
npm install
npm run dev
